# CHUNITHM Unplayed Picker

CHUNITHM-NETからMASTER・ULTIMAの未プレイ楽曲を取得し、次に遊ぶ楽曲をランダム抽選するブックマークレットです。

> [!IMPORTANT]
> 本ツールはCHUNITHM-NETの「レコード」機能を使用するため、**スタンダードコースへの加入が必要です。**

## 導入

導入ページからブックマークレットをコピーしてください。

**https://maqlaguh.github.io/chuni-unplayed-picker/**

1. 導入ページの「コピーする」を押します。
2. ブラウザで任意のページをブックマークします。
3. 作成したブックマークを編集し、URL欄をコピーした内容へ置き換えます。
4. CHUNITHM-NETへログインします。
5. CHUNITHM-NET内で作成したブックマークを実行します。
6. 初回起動後、「一括更新」を押して楽曲情報を取得します。

## 全曲埋めた人へ

全曲埋めた人のためにモードを追加しました。埋めないとそのモードにならないので頑張ってください。

## 主な機能

- CHUNITHM-NETの任意ページから起動
- MASTER・ULTIMAの楽曲情報を一括更新
- 楽曲名、ジャンル、レベルを取得
- 指定曲数を重複なしでランダム抽選
- 対象楽曲を難易度別・全体の一覧から確認
- 抽選結果の並び順を完全ランダム・昇順・降順から選択
- 抽選結果・楽曲一覧から任意の曲を次回抽選へKEEP
- 抽選結果を縦長PNGとして保存・共有
- 未解禁の可能性がある譜面へ鍵マークを表示
- 未解禁曲を抽選対象から除外する設定
- プレイ状況に応じて利用できる追加機能
- スマートフォン対応のフローティングパネル
- CHUNITHM-NETのプレイ履歴・クラス認定を参考にした表示
- ブラウザのLocalStorageへのデータ保存
- 起動時に最新版を自動取得

## 解禁が必要な楽曲

CHUNITHM-NETだけでは解禁状態を取得できないため、解禁が必要な楽曲はツール内の一覧で管理しています。

- 一覧に含まれ、スコアがない譜面は未解禁候補として扱います。
- 一覧に含まれていても、スコアがある譜面は解禁済みとして扱います。
- 未解禁候補はカードに鍵マークが表示されます。
- 「設定」から未解禁候補を抽選対象から除外できます。

この判定はCHUNITHM-NET上のスコアとツール内の定義に基づく推定です。

## データについて

取得した楽曲情報と設定は、実行したブラウザのLocalStorageへ保存されます。共有画像もブラウザ内で生成し、外部サーバーへのユーザーデータ保存は行いません。

データを更新する場合は、CHUNITHM-NETへログインした状態で「一括更新」を押してください。取得に失敗した場合、既存の保存データは保持されます。

保存データは「設定」から削除できます。

## 対応環境

- JavaScriptブックマークレットを実行できるモダンブラウザ
- CHUNITHM-NETへログインできる環境
- CHUNITHM-NETのスタンダードコースに加入しているアカウント
- Chrome系ブラウザ推奨

ブラウザの設定や仕様によっては、ブックマークレットの登録・実行方法が異なる場合があります。

## 注意事項

- 本ツールは非公式です。
- SEGAおよびCHUNITHM公式とは関係ありません。
- CHUNITHM-NETの仕様変更により動作しなくなる場合があります。
- 使用は自己責任でお願いします。
